Problem Statement Coverage (Team: Entangled Minds)
Use Case 03: Irrigation and water-resource allocation optimisation
Quantum AI / ML Approach: Combinatorial QAOA and QUBO Simulated Annealing solver that balances reservoir release schedules, minimizes downstream conveyance/evaporation losses, and minimizes the Gini equity disparity between head-reach and tail-end command areas (such as Rayalaseema SRBC and Western Godavari distributaries).
Stakeholder Coordination: Configured for the Andhra Pradesh Water Resources Department, Central Water Commission (CWC), KGBO, and Command Area Development irrigation boards.
